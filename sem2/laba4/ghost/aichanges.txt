ВАЖНЫЕ ИНСТРУКЦИИ ИЗ ПРЕДЫДУЩИХ СЕССИЙ (ИСТОРИЯ ПРАВОК):
При генерации блок-схем я просил делать следующие исправления, которые теперь являются обязательными стандартами:

1. Идеальное примыкание стрелок (без нахлеста на блоки): 
   - Проблема: Концы стрелок налезали на границы блоков.
   - Решение: В `<marker id="arrow">` необходимо жестко задать `refX="10"`, `markerWidth="10"`, `markerHeight="10"` и ОБЯЗАТЕЛЬНО добавить `markerUnits="userSpaceOnUse"`. Координаты линий (`d="M... L..."`) должны рассчитываться точно до пикселя границы целевого блока (например, целевой Y - 60). Не нужно делать "отступы в 5px", острие маркера теперь идеально ложится на конец линии.
2. Масштаб и заполнение формата А4: 
   - Проблема: Схема была слишком мелкой на огромном холсте, оставалось много пустого места.
   - Решение: Использовать пропорции `viewBox="0 0 1050 1485"` с физическими размерами `width="210mm" height="297mm"`. Основной шрифт увеличен до 15px.
3. Английские коннекторы:
   - Проблема: В кругах-соединителях использовалась кириллица, что ломало единообразие.
   - Решение: В коннекторах (внутри кругов переходов на другие колонки/страницы) использовать ТОЛЬКО заглавные английские буквы (A, B, C, D...).
4. Локализация на белорусский язык:
   - Термины ГОСТ должны быть на белорусском: «Пачатак» (Начало), «Канец» (Конец), «выклік ф.» (Вызов функции), «Ув:» (Ввод), «Вывад:» (Вывод), «Так» (True), «Не» (False).
5. Колонки и многостраничность:
   - Если блок выходит за пределы Y=1350, нужно ставить коннектор, переходить на колонку 2 (X=750, Y=100) на той же странице. Если и вторая колонка заполнена — закрывать тег `</svg>`, обрывать код-блок и начинать следующий markdown-блок для Страницы 2.

1. GOST Methodology: Block Types & Semantic Rules (BELARUSIAN LOCALIZATION)

Before drawing, analyze the code and map operations to the correct GOST symbols.

  - Terminal -> ID: #term
      - Usage: main() start, return, exit().
      - Text: "Пачатак" (Start) or "Канец" (End).
  - Process -> ID: #rect
      - Meaning: Data processing, mathematical operations, value assignment.
      - Text: Write the exact mathematical operation.
  - Predefined Process -> ID: #proc
      - Usage: Calling a function, free(), printf(), etc.
      - Text Rule: Top line MUST be "выклік ф.". Bottom line is the function signature.
  - Decision -> ID: #rhomb
      - Usage: if, while, for.
      - Text Rule: Write the logical condition. Place text labels "Так" (True) or "Не" (False) 
        OUTSIDE the block on the exiting arrow paths.
  - Input / Output -> ID: #io
      - Text Rule: Prefix with "Ув:" (Input) or "Вывад:" (Output).
  - Connector -> ID: #conn
      - Usage: Jumping between columns or pages.
      - Text Rule: MUST use strictly English capital letters (A, B, C...).
